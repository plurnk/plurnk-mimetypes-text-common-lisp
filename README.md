# @plurnk/plurnk-mimetypes-text-common-lisp

text/x-common-lisp mimetype handler for plurnk-service. Hand-rolled S-expression scanner (no ANTLR).

## Install

```sh
npm install @plurnk/plurnk-mimetypes-text-common-lisp
```

## Versioning

This package versions independently. Compatibility is declared by its dependency
ranges; a Plurnk release does not require a release of this package.
